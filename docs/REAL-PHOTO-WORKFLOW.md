# 天气照片版工作流（公开、可审阅记录）

本文件记录新版第一章实际采用的创作和制作路径，并严格区分已执行工作、公开源代码和许可尚未确认的本地环节。

## 设计原则

- 保留奶油白、黑色、红色强调与克制排版；不因使用真实照片而替换原有设计风格。
- 真实照片承担具象呈现，原创图解承担范围、时间、概率与偏差等抽象解释。
- 每张照片注明来源与证据范围；历史设备照不能冒充现代观测画面。
- 演绎示意须直接标注“教学示意”或“概念图”，不伪造成卫星、雷达、地图或实测数据。
- 旁白采用用户指定的普通话女声；准确语音标识必须记录，不能仅凭显示名或音频文件名判断语种。

## 实际制作顺序

1. **核验来源**：为云照片与历史雷达设备照片保存来源页、作者/机构、日期、许可声明与原图 SHA-256。公开版本引用原始来源链接。
2. **照片预处理**：本地 ComfyUI 对许可照片执行 `LoadImage → ImageScale (Lanczos) → SaveImage`。该流程只调整采样尺寸，不运行扩散模型、不生成新云形、不改写实测数据。本次设备照执行结果记录在本地工程；本工作流 JSON 是去除本机路径后的可重用结构示例，不包含媒体文件或模型。
3. **旁白生成**：在本机用 macOS 离线 `say` 的准确标识 `com.apple.voice.compact.zh-CN.Tingting` 重新生成。新旧语音首句做 PCM 数据对照，避免旧缓存误复用。系统声音再分发许可未核实，因此音频及句级缓存只留本地审阅，不加入公共仓库。
4. **按句生成字幕时间**：用每句音频的起止点建立句级字幕；句间停顿为 0.18 秒，场景间额外停顿为 0.52 秒。该做法不是逐词强制对齐。
5. **完成第一章画面**：把真实照片、排版、原创 SVG 教学图解和 22 条字幕放入五场景预览；用音频绝对时间驱动字幕和画面切换。该工程以本地浏览器和普通 HTML/SVG 实现，不是 HyperFrames 项目。
6. **本地核验**：检查准确声音标识和音频帧、逐句拼接、音频 URL、完整播放结束、字幕内容、定位可重复性、画面边界、控制项、手机布局和素材加载。自动检查不能替代人工听审、气象专家审签或逐词对齐检查。
7. **交付边界**：当前只有第一章画面完成；全稿配音长度约 16 分 39 秒并不代表全片画面完成。未导出 MP4。公开仓库不带配音，所以 GitHub 源文件本身不能复现本地有声播放。

## ComfyUI API 工作流示例

`../workflows/weather-photo-resample-api.json` 展示无需模型的三节点重采样流程。启动本机 ComfyUI 后，应把 `INPUT_PUBLIC_DOMAIN_PHOTO.jpg` 替换为已经核验许可、并放入 ComfyUI 输入目录的照片文件名。`OUTPUT_PREFIX` 只用于组织输出文件名。实际输出尺寸应按输入长宽比与画面裁切策略选择，不应把工作流示例尺寸误解为本次所有照片统一尺寸。

这个 JSON 是流程模板，不含本机路径、照片文件、模型权重或凭证，也不声称在其他机器上已经执行成功。

## 语音核验说明

系统语音显示名称不是可靠的语种锁定机制。实际制作曾发现旧显示名调用的 PCM 与明确指定的粤语 Sinji 输出一致；新版改用准确的 Tingting `zh-CN` 标识，并用 PCM 对照验证首句。普通话女声的“系统目录语言和性别标签”与“听感人工评审”是两种证据；前者不能代替后者。不要公开传播本地系统声音，除非已核实对应版本的再分发许可。

## 公开复现限制

公开仓库包含本说明和 ComfyUI 节点结构，不含私有音频、逐句语音缓存、完整照片文件或模型权重。照片由其权利人/许可条件决定再分发方式，本仓库提供出处而非默认复制二进制素材。当前本地预览源码仍依赖不公开的声音文件，故没有将其伪装成可在线完整播放的 GitHub 页面。
