## 创作方向

沿用已经确认的奶油白（`#F1EEE7`）、黑色（`#181818`）、红色强调（`#DA291C`）与精简排版。开场用有来源的真实积雨云照片，并以克制推近呈现；后续用真实历史雷达设备照片解释设备外观，再用明确标注的教学示意解释抽象概念。真实照片不承担超出其证据范围的作用：云照片不是某次预报准确性的证据，1973 年雷达设备照片也不是现代雷达回波。

真实素材只做裁切、缩放和轻微推近，不生成云或伪造气象观测。城市格网、时间线和雨区轮廓属于原创教学图解；必须标明示意，不伪装成地图、雷达产品或定量观测。

## 第一章内容结构

1. 以堪培拉真实积雨云照片提出“预报为什么会报不准”的问题，注明摄影者、地点与日期。
2. 以 NOAA/NSSL 的 1973 年历史研究雷达设备照片说明仪器外观；流程图仅表示观测、计算、信息表达的概念链路，不声称对应某个天气应用。
3. 用教学格网区分城市与街道等空间范围，并说明时间窗口、变量和事件阈值也必须对齐。
4. 区分模式起报、信息发布时间、预报有效时间和预报提前量；说明较早发布的降雨预报与临近雷达外推任务不同。
5. 以概念轮廓解释位置、时间和强度偏差，明确其不是雷达图。
6. 区分一次个人体验与多地点、多时次的长期检验，并说明不同决策有不同的漏报容忍度。

## 配音语种错误与修正

旧版曾将系统声音显示名 `Tingting (Chinese (China mainland))` 当作语种选择依据。实际诊断发现，该调用的首句 PCM 数据与明确指定粤语声音 `com.apple.voice.compact.zh-HK.Sinji` 的对照输出逐字节一致；旧版“已换为普通话”的说法因此撤回。

新版使用 macOS 离线 `say` 的精确普通话声音标识 `com.apple.voice.compact.zh-CN.Tingting`。首句 PCM 对照与准确指定 Tingting 的输出一致、与 Sinji 输出不同；本机声音目录将其列为 zh-CN 女声。第一章 22 句重新合成，并重算字幕、场景边界和画面动作时间。修复细节、音频散列和检查范围见本地制作记录；出于再分发许可未核实，实际 WAV 与逐句缓存不进入本仓库。

此证据证明使用的系统声音标识及音频数据对照，不等于人工听审、发音自然度评价或逐词字幕对齐。第一章曾在本地浏览器完成完整播放、字幕与画面同步、定位、控制项和手机布局检查；本仓库未包含配音，不能据此宣称 GitHub 上的公开文件可重现有声预览。
