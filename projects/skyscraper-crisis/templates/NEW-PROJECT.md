## 先写完整旁白

沿用 `## 01｜章节名` 的 8 章结构时，解析器按空行分段，一段对应一个 `CHAPTERS["shots"]` 条目。改变章节数或格式时需要同步调整解析器和节点范围。

```text
## 01｜章节名

第一段完整旁白。

第二段完整旁白。
```

## 工程替换位置

1. `SCRIPT_FULL_V1.md`：完整台词。
2. `full_film.py / CHAPTERS`：章标题、段落对应的模式、标题与解释。
3. `v2_plan.py / ASSETS`：镜头 ID、所属章节与主体动作。
4. `v2_plan.py / BEATS`：每段有序素材列表。
5. `v2_plan.py / PROOFS`：必须看见的画面证据。
6. `v2_visuals.py / KEYWORDS`：按旁白关键词切镜的时间锚点。
7. `v2_visuals.py`：金额、时间线、来源卡和专题图解。
8. `full_film.py / voice_paragraph`：自己的声音、语速与缓存键。

## 验收与交付

- 先确认旁白，再看关键场景的起中末帧。
- 所有具体名词和动作都能找到对应画面。
- 不把生成文字当成真实合同、文献或数据。
- 具名对象形状准确，来源和用途记录清楚。
- 先生成短核对片，再合成全部章节。
- 保存字幕、时间线、seed、工作流与失败候选说明。
- 检查完整解码、音画时长和版本文件哈希。
- 在 README 追加迭代记录，保留已有项目。
