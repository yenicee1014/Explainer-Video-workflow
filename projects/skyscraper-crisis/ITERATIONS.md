# 迭代记录与验收

整理日期：2026-10-25。原始台词、历史方案和对话保留；后续修改请增加日期条目。

## 1. 先确定视觉方向

需求是灰白纸纹、黑白建筑剪贴、粗标题和暗红强调。10 秒 demo 验证了方向，但只围绕一栋楼，不能代替完整科普内容。早期暗色写实 CG 提示词被标记暂停，见 `history/demo/PROMPTS.md`，不能误当成最终提示词。

## 2. 完整台词先于全片生成

用户反馈“风格是对的，但没有表现台词对应情节”，要求先写完整台词。随后形成 `SCRIPT_FULL_V1.md`：8 章、78 段。台词使用历史时间线、虚构贷款项目与证据检验来组织内容，避免只靠建筑画面推进叙事。

用户接着要求按 01–08 顺序生成。V1 虽然具备完整旁白，素材仍偏泛化；不能用“每章一段素材”推断“每句内容已经被表现”。

## 3. 从段落主题变成可观察动作

第二次纠偏明确提出失业、借贷签约、工地竞争、租户减少、再融资和证据检验六类现象。V2 增加 23 条采用的机制素材，并为每段安排有序画面节拍，总计 148 个。

每个镜头先问三个问题：

1. 台词里出现的主体、物件，观众是否真的看见？
2. 动作是否解释经济机制，例如签字、交钥匙、比较旧新合同？
3. 把旁白静音后，这段画面是否仍能区分于其他现象？

## 4. 地标生成失败后的替换

`esb_motion` 与 `burj_motion` 候选未通过建筑轮廓审查。V2 没有继续将失真建筑充作真实地标，而是选取已记录来源的整栋建筑照片，通过后期构图和克制运镜保持同一美术语言。

失败候选的 brief、API 和核对图仍保存，用于说明失败方式；素材包不收录被弃用候选视频。最终渲染中的同名键映射至准确照片，见 `v2_visuals.Media.path()`。

## 5. 数字、文献与历史影像各自核对

生成视频只负责无字情境。金额与利率由后期排版，按同一虚构项目连续计算。现代建筑参考照片不冒充开幕当天的档案；论文书目卡是重新排版的引用，不冒充期刊页面截图。

已保存 Crossref 书目信息，未取得期刊全文。工程中保留这一限制，不能把有 DOI 误写成已完整复核所有统计方法。

## 6. 成片验收与本次同步

制作阶段已有：

- 每条新镜头起、中、末三帧核对图。
- 每章画面节拍与旁白对应的 contact sheet。
- 合同、搬离、再融资和样本检验的选段审查。
- 旁白文本一致、章节音画时长与素材存在检查。
- 完整成片 FFmpeg 解码检查。
- 六类现象核对片和最终完整版。

本次同步增加原文件 SHA-256、公开源工程、环境变量配置、素材包清单、创作对话、复用模板和 GitHub 播放入口。制作报告是历史核验记录，本次同步的文件完整性以 `delivery-manifest.json` 为准。
