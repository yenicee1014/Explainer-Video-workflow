# ComfyUI 制作方案：先参考分析，再搭建，再试片

更新：2026-10-24  
状态：技术方案，不是已安装、已跑通的整套 workflow JSON。  
执行限制：本轮不生成、不安装节点、不提交云端计费任务。

## 1. 本轮纠偏

- 已在链接播放器观察前段若干采样，详见 `REFERENCE_ANALYSIS.md`。
- 采样中的主要表达是灰白纸纹/网点、黑白建筑剪贴、红色标记和信息排版，不是写实夜景 CG。
- 全片逐帧分析尚未完成，不能将前段观察泛化为全部 9 分 52 秒。
- 旧版 70 秒成片、八段写实 CG、每镜头 10 秒均未经用户确认，撤回为待定。
- 已明确的要求：横屏、方案先行、整套 ComfyUI 流程；以后先交付 10 秒预览，用户确认才继续。
- 可借鉴一般美术语言；采用新脚本、新素材、新布局，不交付逐镜近似复制且仅替换措辞的“洗稿”。

## 2. 参考理解与证据

### 网页可继续，文件为精确分析的可选输入

此前的登录弹窗已通过正常关闭按钮关闭，网页仍能观看，不能再将“必须上传文件”当作风格研究的前提。
可以继续逐镜截图，记录画面事实并设计新素材提示词；运动与转场须连续播放确认，不能凭单张截图断言。
网页采样要核对 URL、标题、实际解码画面，排除自动连播、播放器遮挡和 seek 后残留帧。
本轮读到当前参考播放流为 640×360、592 秒；这不是上传母版参数。
本地文件用于更准确的源参数核实与逐帧扫描；只有正常网页观看实际受阻时，才需要用户登录或提供文件。
没有提取隐藏流、绕过登录或下载参考视频。

### 获得可分析文件后的步骤

1. 核对真实时长、宽高、帧率、音轨；不预设原片是 24 或 30 fps。
2. 全片播放理解内容；记录结构、事实论点、画面类型，不将原字幕改写充当原创脚本。
3. 固定间隔采样建立覆盖，再按实际切镜点补充。等间隔截图可能漏掉短镜头，并非完整分镜表。
4. 对选定的 10 秒研究片段逐帧检查；对切镜、标题入场、图表动作细查时序。
5. 全片其他镜头记录开始/中间/结束与动作转折；只有实际检查全部帧才称全片逐帧分析。
6. 观察表字段：时间码、画面类型、前中后景、字体类别、色彩、运动、转场、字幕区、来源、确认程度。
7. 将一般视觉方法映射为原创制作，不复用整套独特构图、镜头顺序、作者标识或音轨。

## 3. 本机接口审计

来源：本机 `http://127.0.0.1:8188` 只读接口；未读取或记录 API 密钥。

### 环境

- `/system_stats` 报告 ComfyUI 后端 `0.34.0`，不是桌面壳或标题栏版本。
- 设备为 MPS，总内存约 16 GiB；检查时可用约 4.3 GiB，运行时会变化。
- `/queue` 检查时运行与等待队列均为空。
- 本机可找到 ffmpeg、ffprobe、node、python3；仅确认存在，尚未验证全部字体、滤镜和编码能力。

### 已注册的相关节点

| class_type | 核实用途 | 限制 |
|---|---|---|
| `LoadImage` | 输出 IMAGE、MASK | PNG 透明度与 MASK 的实际语义需测试图验证 |
| `ImageScale` | image、upscale_method、width、height、crop | 统一静帧尺寸，避免拉伸建筑 |
| `ImageCompositeMasked` | destination、source、x、y、resize_source；可选 mask | 单帧合成，自身不是可关键帧化的时间轴 |
| `TextOverlay` | text、font_size、color、position、align、outline | 仅 top/bottom 与三种对齐；没有自选字体、任意坐标或字距参数 |
| `LoadVideo` | file → VIDEO | 文件枚举/上传，不承诺能直接连接路径 STRING |
| `GetVideoComponents` | VIDEO → IMAGE、AUDIO、fps 等 | 长视频解码成批前需检查内存 |
| `CreateVideo` | images、fps；可选 audio 等 → VIDEO | 帧批封装，不提供复杂排版和时间轴 |
| `SaveVideo` | video、filename_prefix、format | 当前含动态 codec 配置，需按安装版本导出 |
| `AutoDLWorkflow` | workflow_id、schema_json、动态 ad_* 槽位 | 能力由具体远端 schema 决定 |
| `AutoDLPreviewVideo` | video → VIDEO | 历史成功任务使用的预览节点 |

注册不等于模型权重、授权、账户余额和可执行能力均已验证。
本次检查未发现 VHS 系列、IPAdapter 或专用时间轴排版节点；未据此安装任何包。

### 已成功历史任务的 H3 云链

工作流标识：`minimax_h3_lightx2v_no_pic`，历史 schema 版本 6。
这是历史成功接口快照，不是重新刷新验证过的远端目录。

```text
PrimitiveInt（duration） ───────────→ ad_int_01
PrimitiveStringMultiline（prompt） → ad_text_01
CustomCombo（resolution） ─────────→ ad_text_02
PrimitiveInt（seed） ──────────────→ ad_int_02
                                   AutoDLWorkflow
                                   ad_out_01: VIDEO
                                           ↓
                                   AutoDLPreviewVideo
```

| 参数 | 历史 schema 范围 |
|---|---|
| duration | 整数 1–15 秒 |
| prompt | 必填，1–20000 字符 |
| resolution | `480p竖`、`768p竖`、`480p横`、`768p横`、`480p(1:1)`、`768p(1:1)` |
| seed | 整数 1–999999999999999 |

重要更正：

- 不接受把 `1280x720` 直接当作 resolution 枚举值。
- “横”不证明输出精确为 16:9，必须实测宽高与显示宽高比。
- 此历史 schema 没有独立 negative_prompt、fps、图片参考或视频参考字段。
- 通用节点有 ad_image_* 槽位，不等于这个文生视频 workflow 能接图。
- 可将排除要求写入 prompt，但不保证等同独立负面条件。
- 固定 seed 不保证建筑连续性或跨模型复现。
- 报价、余额及计费规则未核实，费用未知；本轮不提交任务。

## 4. 主流程：分层图文动画

### A. 项目与素材清单

输入为原创脚本、分镜表、来源清晰的图片/纹理、设计参数。

```text
assets/backgrounds/   新制作或可用授权的纸纹、网点
assets/buildings/     授权历史图片，或标注为示意的原创建筑图
assets/graphics/      自行绘制的曲线、箭头、数字与图形
assets/audio/         新旁白、可用授权的音乐与音效
storyboard/           分镜、布局、时序、字幕
renders/              后续的静帧、草片、验收报告
```

历史案例与年份另行核实；生成式示意图不能伪装成真实档案照片。

### B. 静帧合成与美术确认

```text
LoadImage：背景 ───────────────────────────┐
LoadImage：建筑 → ImageScale → mask 核对 ──┼→ ImageCompositeMasked
LoadImage：原创图形 ───────────────────────┘          ↓
                                            静帧预览/保存
```

- 先确认纹理、灰阶、建筑边缘、红色强调与留白。
- 选用能正常显示中文、授权合适的字体；不声称已找到原片字体。
- 标题、数字、正文、字幕分层；可读中文不交给生成模型负责。
- 任意坐标与混合字体标题预制为透明图层，不把 TextOverlay 当成完整设计工具。
- 静帧确认后才做动态；本轮仅写计划，不实际出图。

### C. 时间轴：需要补齐的能力

现有基础节点不足以直接表达多层关键帧、统一缓动、镜头切换、任意字排。
不能再用未验证的 “Line / Curve / Concat Clips” 冒充已跑通节点。

建议批准后开发项目专用节点组，暂名 `EditorialTimelineRender`。
此名称为设计提案，当前未安装、未实现。

拟定契约：

- 输入：素材目录、分镜 manifest、宽高、fps、目标帧数、输出前缀；音轨和字幕可选。
- manifest：各层素材、起止帧、锚点、位置、缩放、透明度、遮罩、缓动、图层顺序。
- 操作：确定性的平移、缩放、淡入、遮罩揭示、图表描边，不让模型逐帧重画文字与建筑。
- 渲染：本地逐帧/短块处理后交给 FFmpeg 编码，避免完整高清 float32 IMAGE 批次驻留内存。
- 输出目标：兼容当前后端的 VIDEO 和验收报告；实际对象构造与端口兼容性待实现验证。
- 安全：manifest 只作数据，不允许任意 shell；限制素材路径，不覆盖输入、不含密钥、不访问云 API。
- 重复渲染同一 manifest，图层位置与字排一致；随机纹理记录明确 seed。

以下是架构提案，不是可导入 JSON：

```text
已确认 manifest + 素材 + 中文字形图层
                  ↓
       EditorialTimelineRender（待开发）
                  ↓ VIDEO（待验证）
            SaveVideo → 本地 MP4
```

不安装自定义节点的备选是本地脚本渲染、再以 LoadVideo 导入；
这属于“ComfyUI 配合本地后期”，不称为整套都已在 ComfyUI 内完成。

### D. 可选 AI 素材支路

只有分镜确实需要时才启用，不默认批量生成。

- 历史已核实 H3 链仅用于原创无字素材；不承担整段信息图制作。
- 图生图、背景移除、风格参考、图生视频先核对具体 schema、模型与授权，再确定接线。
- 未确认图像参考能力前，不写“参考帧接 H3”的虚假方案。
- 不将参考视频或截图上传第三方生成服务；后续上传先说明具体素材、接收服务和目的。
- 每次云提交前确认工作流、横屏枚举、时长与费用。
- AI 素材只占对应图层；标题、图表数值、字幕、时间轴采用可控合成。

### E. 旁白、字幕与最终合成

- 先确认原创 10 秒旁白，再依据读音时长安排画面；不复用原片音轨或克隆作者声音。
- TTS 服务与节点未核实，不宣称现成可用。
- 中文缺字测试前置；字幕与数值作为独立图层。
- 音乐、音效采用新制作或可用授权素材，来源写入清单。
- 混音、字幕、编码拟并入本地渲染节点；实现前不称为完成。

## 5. 10 秒预览验收提案

这是新的风格验证单元，不是原片开头 10 秒的镜头复印。
内容和分镜在完整参考观察后再写，不在此编造原片镜头。

建议规格，待确认而非原片实测参数：

- 1280×720、16:9、25 fps、250 帧，目标 10.000 秒。
- 覆盖建筑剪贴、信息标题、图形运动，验证整套设计系统。
- 静帧确认 → 本地动态 → 必要时才启用获批的付费素材生成。
- 1080p 是候选终稿目标；不把低分辨率拉伸称作真正增加细节。

验收：

- ffprobe 核对宽高、SAR/DAR、帧率、时长、音轨。
- 检查首帧、中间帧、末帧，转场逐帧检查。
- 中文无缺字、文字不扭曲、边缘无明显黑边、字幕不重叠。
- 数字与旁白对齐，无越界、闪帧；灰阶与红色遵循确认后的美术板。
- 来源明确，无原作者标识、原片音轨残留。
- 保存 manifest、节点版本、参数、输出位置、验收结果，才能继续批量。

## 6. 执行顺序与停止点

1. 参考理解：继续正常网页观察、逐镜采样；精确逐帧研究可使用用户提供的本地文件。
2. 设计方案：美术板、原创分镜、素材来源表，交用户确认。
3. 工作流实现：补齐时间轴节点，导出 UI workflow JSON 与 API prompt JSON，离线校验端口。
4. 本地验证：用自制测试素材检查中文、透明度、关键帧、内存、编码，不触发云 API。
5. 十秒预览：仅制作已批准测试段；需云素材则先确认费用。
6. 暂停等待：交付预览后停止，用户确认再做全片。

已完成：前段采样记录、本机接口审计、纠偏方案。  
未完成：全片分析、美术板、原创分镜、节点开发、可执行整套 JSON、新十秒预览。
